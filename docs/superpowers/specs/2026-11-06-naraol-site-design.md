## 1. 목적과 범위

(사)나라얼연구소의 **공식 홈페이지**를 새로 만들어 GitHub Pages로 호스팅하고 `naraol.org`에 연결한다.

**용도**: 지원사업 신청 시 제출하는 공식 사이트. 심사위원이 단체의 성격과 그동안의 실적을 빠르게 파악하고 신뢰할 수 있어야 한다. 행사 신청·소식·자료 업데이트는 **다음카페**에서 하고, 홈페이지는 그곳으로 연결만 한다.

**배경**
- 도메인 `naraol.org`는 Wix에서 등록했고 현재 어떤 사이트에도 연결되어 있지 않다.
- 예전 Wix 사이트(`https://jennyjhshin.wixsite.com/my-site-2`)는 콘텐츠 원본으로 쓴다.
- 전체 연혁(강좌 1~170회, 학술대회 1~12회)과 법인 정보는 제니가 문서로 정리해 전달한다.

**성공 기준**
1. 심사위원이 홈에서 30초 안에 단체의 목적, 핵심 실적 숫자, 주요 사업을 파악할 수 있다.
2. 연혁·학술대회·강좌 기록이 빠짐없이 정리되어 있고, 인쇄하거나 PDF로 저장하면 A4에 깔끔하게 나온다.
3. 법인 정보(설립일, 주무관청, 고유번호, 대표자 등)가 명시되어 있다.
4. `https://naraol.org`(및 `www`)에서 HTTPS로 열리고, 휴대폰(375px)과 PC에서 모두 읽기 편하다.
5. 실적을 추가할 때 데이터 파일 한 곳만 고치면 홈 숫자·요약·상세 페이지가 함께 갱신된다.

**범위 밖 (하지 않음)**
- 행사 신청, 예정/지난 행사 구분, 일정 자동 갱신
- 게시판, 회원 로그인, 결제, 관리자 화면(CMS), 다국어
- 업데이트는 제니가 내용을 주면 크대리가 파일을 고쳐 반영한다

## 4. 콘텐츠 구조

### 데이터 파일 (`src/data/`, 스키마 검증)

**`org.yaml`** — 법인·연락 정보 (꼬리말, 법인 정보, 후원 페이지, 홈 숫자가 공유)
| 필드 | 설명 |
|---|---|
| name | (사)나라얼연구소 |
| founded | 설립일 (YYYY-MM-DD) |
| registeredBy | 주무관청 |
| regNo | 고유번호 또는 사업자등록번호 |
| representative | 대표자(이사장) |
| donationDesignated | 지정기부금단체 여부와 근거 문구 |
| address, phone | 주소, 전화 |
| cafeUrl | 다음카페 주소 |
| kakaoUrl | 카카오톡 채널 |
| bank | 은행, 계좌, 예금주 |
| dues | 회원 종류별 월 회비 |
| heritage | 국가민속문화재 제266호 경산상엿집 (문구) |

**`history.yaml`** — 전체 연혁: `[{ year, items: [{ date?, title, kind? }] }]`
- `kind`: `founding`(설립·지정 등 기관 이력) / `conference` / `lecture` / `academy` / `culture` / `award` / `etc`
- 홈 "최근 3년 주요 실적"은 이 파일의 최근 3개 연도에서 가져온다.

**`conferences.yaml`** — 국제학술대회: `[{ no, year, date, title, theme?, venue, hosts: [string], photo?, pressUrl? }]`
**`lectures.yaml`** — 인문학강좌: `[{ no, date, speaker, affiliation?, topic }]`
**`people.yaml`** — 임원: `[{ name, role, bio: [string] }]` (이사장이 맨 앞)
**`academy.yaml`** — 물볕아카데미: `courses: [{ name, teacher, bio }]`, `terms: [{ title, period, items: [string] }]`
**`books.yaml`** — 물볕서점 추천도서: `[{ title, author, publisher, note? }]`

**홈 숫자 계산 규칙**
- 설립 후 햇수 = 오늘 연도 − `org.founded` 연도 (빌드 시점)
- 국제학술대회 횟수 = `conferences.yaml`의 최대 `no`
- 인문학강좌 횟수 = `lectures.yaml`의 최대 `no`
- 숫자 데이터가 비어 있으면(예: 연혁 문서 전달 전) 해당 숫자 칸을 숨긴다

### 컬렉션 (`src/content/`)
- **press** (언론보도) — `press/YYYY-MM-DD-매체.md`: `title, outlet, date, url?, thumbnail?` + 본문(발췌)
- **photos** (사진 기록) — `photos/이름/index.md` + 사진들: `title, date, cover` + 폴더 안 이미지 자동 수집. 각 사진에 날짜·행사명 캡션 표시

### 페이지에 직접 쓰는 글
설립 목적·비전·인사말, 경산상엿집 소개, 문화공간 물볕 소개, 후원 안내 문구

## 5. 디자인

**방향**: 한지·먹, 기관 문서 톤 — "기록이 잘 정리된 학술 단체의 기록집." 단체의 전통문화 성향을 보여주되, 화려함보다 정돈과 절제로 신뢰를 준다.

| 토큰 | 값 | 용도 |

| `--paper` | `#F5F0E6` | 배경 (미색 한지) |
| `--paper-deep` | `#EAE2D2` | 카드·구획 배경 |
| `--ink` | `#2B2B2B` | 본문 글씨 (먹) |
| `--ink-soft` | `#5A554D` | 보조 글씨 |
| `--accent` | `#A83A2E` | 단청홍 — 숫자, 회차 표시, 구분선에만 절제해서 사용 |
| `--line` | `#D6CCB8` | 표·타임라인 선 |

- **글꼴**: 제목·숫자는 Noto Serif KR, 본문은 Pretendard
- **로고**: 기존 빨간 지붕 로고 사용 (Wix에서 원본 추출)
- **실적 표현**: 큰 명조 숫자, 세로 타임라인(연도 + 항목), 회차 표(학술대회·강좌)
- **사진**: 장식이 아니라 증빙. 날짜·행사명 캡션을 반드시 단다
- **반응형**: 휴대폰 16px 여백, 카드 1→2→3열, 표는 휴대폰에서 카드형으로 바뀜, 한글 `word-break: keep-all`
- **인쇄 스타일**: 머리말·꼬리말 메뉴·버튼을 숨기고, 흰 바탕에 A4 여백, 표가 페이지 경계에서 행 단위로 나뉘며, 링크 뒤에 주소를 표시하지 않는다. 각 페이지 상단에 단체명·페이지명·출력일을 표시한다
- **접근성**: 본문 대비 4.5:1 이상, 이미지 대체텍스트, 키보드로 메뉴 조작 가능
- 다크 모드는 지원하지 않는다

## 7. 콘텐츠 이전과 수집

1. 예전 Wix 페이지 텍스트를 추출해 4장의 데이터·컬렉션으로 옮긴다 (임원, 2021~2024 연혁·강좌, 상엿집, 학술대회, 물볕아카데미, 물볕공간 추천도서, 언론보도, 후원).
2. 이미지는 Wix 이미지 서버(`static.wixstatic.com`)에서 원본 해상도로 받는다.
3. Wix 이벤트·블로그 게시물(제12회 국제학술제, 제9회 국제학술대회, 인문학포럼 등)은 행사 페이지가 아니라 **실적 기록**(`history.yaml`, `conferences.yaml`, 사진 기록)으로 옮긴다.
4. 제니가 전달하는 **전체 연혁 문서**와 **법인 정보**를 `history.yaml`, `lectures.yaml`, `conferences.yaml`, `org.yaml`에 반영한다. 전달 전에는 Wix에서 확인된 범위로 먼저 만들고, 비어 있는 숫자 칸은 숨긴다.

## 8. 배포와 도메인

1. GitHub 저장소 생성 후 Pages 소스를 "GitHub Actions"로 설정한다.
2. `.github/workflows/deploy.yml`: `main` 푸시·수동 실행 시 빌드 → 테스트 → 링크 검사 → 배포. 검사 실패 시 배포하지 않는다.
3. `public/CNAME` = `naraol.org`
4. Wix 대시보드 → 도메인 → naraol.org → DNS 레코드: 기존 Wix A/CNAME 삭제, A(@) `185.199.108.153` `185.199.109.153` `185.199.110.153` `185.199.111.153`, CNAME(www) `<계정>.github.io`
5. 도메인 확인 후 Enforce HTTPS
6. DNS 변경은 계정 설정 변경이므로 진행 전 제니에게 확인받고 함께 진행한다.

## 9. 오류 처리와 검증

- **빌드**: 데이터 스키마 검증 (필수 필드 누락·형식 오류 시 빌드 실패 → 배포 안 됨)
- **단위 테스트**: 홈 숫자 계산, 최근 3년 추출, 날짜 표기
- **링크 검사**: 빌드 결과의 내부 링크·이미지 깨짐 검사 (한글 경로 포함)
- **비어 있는 데이터**: 숫자·섹션이 비면 빈 칸 대신 숨김
- **404 페이지**: 홈·연혁으로 가는 링크
- **화면 확인**: 휴대폰(375px)·PC(1280px)에서 주요 페이지, 가로 스크롤 없음
- **인쇄 확인**: 연혁·학술대회·강좌 페이지를 브라우저 인쇄 미리보기(A4)로 확인
