**성공 기준**
1. `https://naraol.org`(및 `www`)에서 새 사이트가 HTTPS로 열린다.
2. 휴대폰(375px)과 PC에서 모두 읽기 편하다.
3. 새 행사·언론보도를 파일 1개 추가로 올릴 수 있고, 홈·목록·상세가 자동 반영된다.

**범위 밖 (하지 않음)**

- 관리자 화면(CMS) — 업데이트는 제니가 내용을 주면 크대리가 파일을 고쳐 반영한다

## 4. 콘텐츠 구조

`src/content/` 아래 Content Collections로 관리하며, 각 컬렉션은 스키마(zod)로 검증한다.

### events (행사) — `src/content/events/YYYY-MM-DD-이름.md`
| 필드 | 필수 | 설명 |
|---|---|---|
| title | ✔ | 행사명 |
| start | ✔ | 시작 일시 (예: `2026-01-10T11:00`) |
| end | | 종료 일시 |
| location | ✔ | 장소 |
| category | ✔ | `conference`(국제학술대회) / `lecture`(월례강좌·특강) / `booktalk`(북토크·콘서트) / `academy`(물볕아카데미) |
| poster | | 포스터 이미지 (같은 폴더 상대경로) |
| applyUrl | | 신청 폼 링크 — 있으면 [신청하기] 버튼 표시, 날짜가 지나면 버튼 숨김 |
| summary | | 목록용 한 줄 소개 |
| 본문 | | 상세 내용 (Markdown) |

- **예정/지난 행사 구분**: 빌드 시점 기준으로 나눈다. 정적 사이트라서 날짜가 지나도 다시 빌드해야 반영되므로, GitHub Actions를 **매일 1회 예약 실행**(cron)해 자동 갱신한다.
- `/events/conference/`는 `category: conference`인 행사와 학술대회 소개를 함께 보여준다.

### press (언론보도) — `src/content/press/YYYY-MM-DD-매체.md`
| 필드 | 필수 | 설명 |
|---|---|---|
| title | ✔ | 기사 제목 |
| outlet | ✔ | 매체명 |
| date | ✔ | 보도일 |
| url | | 원문 링크 |
| thumbnail | | 썸네일 이미지 |
| 본문 | | 요약 또는 스크랩 텍스트 |

### gallery (행사 갤러리) — `src/content/gallery/이름/index.md` + 사진 파일
| 필드 | 필수 | 설명 |
|---|---|---|
| title | ✔ | 행사명 |
| date | ✔ | 날짜 |
| cover | ✔ | 대표 사진 |
| 사진 | | 같은 폴더의 이미지 전부를 자동으로 수집 |

### 데이터 파일 (`src/data/`)
- `board.yaml` — 임원: 이름, 직책, 약력(여러 줄)
- `history.yaml` — 연혁: 연도 → 강좌 목록(회차, 날짜, 강사, 소속, 주제)
- `books.yaml` — 물볕서점 추천도서: 제목, 저자, 출판사, 소개
- `academy.yaml` — 물볕아카데미 강좌·강사: 강좌명, 강사, 약력, 학기 기록
- `site.yaml` — 연락처·계좌·카카오 링크 등 공통 정보 (꼬리말·후원 페이지가 공유)

인사말·비전, 경산상엿집, 후원안내, 문화공간 물볕 소개 문단

1. 예전 Wix 페이지 13개의 텍스트를 추출해 4장의 파일 형식으로 옮긴다.

3. 예전 Wix 이벤트(최소 4건: 2026.1 인문학포럼, 2025.12 물볕 동네 배움터, 2025.11 제12회 국제학술제, 2025.8 흠흠신서 강좌)와 Wix 블로그 게시물을 행사·언론보도 파일로 옮긴다.
4. 연혁은 사이트에서 확인된 2021~2024년분을 옮기고, 그 외 기간 자료는 제니에게 받아 추가한다.
5. 예전 Wix 주소 → 새 주소 대응은 하지 않는다 (예전 사이트가 도메인에 연결되어 있지 않았으므로 검색 노출 손실이 작음).

## 8. 배포와 도메인

1. GitHub 저장소 생성 후 Settings → Pages → Source를 "GitHub Actions"로 설정한다.
2. `.github/workflows/deploy.yml`: `main` 푸시 + 매일 1회 cron + 수동 실행 시 빌드·배포한다.
3. `public/CNAME`에 `naraol.org`를 넣는다.
4. Wix 대시보드 → 도메인 → naraol.org → DNS 레코드를 수정한다:
   - A 레코드(@): `185.199.108.153`, `185.199.109.153`, `185.199.110.153`, `185.199.111.153`
   - CNAME(www): `<계정>.github.io`
   - 기존 Wix A/CNAME 레코드는 삭제한다
5. GitHub에서 도메인 확인 후 "Enforce HTTPS"를 켠다.
6. DNS 변경은 제니가 직접 하거나, 크대리가 화면을 보며 함께 진행한다 (계정 설정 변경이므로 진행 전 확인).

## 9. 오류 처리와 검증

- **빌드 단계**: 콘텐츠 스키마 검증(필수 필드 누락, 날짜 형식 오류 시 빌드 실패 → 배포되지 않음)
- **링크 검사**: 빌드 결과물의 내부 링크·이미지 깨짐을 자동 검사
- **404 페이지**: 한지 톤의 안내 + 홈·행사로 가는 링크
- **신청 링크 없음**: 버튼을 숨기고 "문의: 카카오톡 / 전화"를 표시
- **화면 확인**: 로컬 미리보기에서 휴대폰(375px)·PC(1280px) 주요 페이지를 직접 확인
- **배포 후**: `naraol.org`, `www.naraol.org`, HTTPS 리다이렉트를 확인
